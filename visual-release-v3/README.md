# 独立外观版本 v3
此版本仅增加外观与三维互动。注册、登录链接指向原站真实路径，未复制、替换或修改服务端接口、数据库、登录规则或权限。
旧版保留在 design-demos/b-court-v1.html 和 design-demos/b-court.html，原生产域名不覆盖。
中文字体 Noto Sans SC：标题 900、按钮 700、正文 400。
三维球按26孔、72mm直径/10mm孔径比例绘制，模型非某厂商产品复刻。拖动旋转、点击/键盘弹跳，定期弹跳，支持减少动态和 WebGL 降级。
部署为独立 Vercel 项目 pku-floorball-visual-v3，账号 tonys-projects-edca53cd。

线上地址：https://pku-floorball-visual-v3.vercel.app/
